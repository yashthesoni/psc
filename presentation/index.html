Project Presentation

Password Strength Checker

A privacy-focused password evaluation tool powered by k-Anonymity & security heuristics.

Problem & Solution

  • Problem: Users choose weak, predictable, or already leaked passwords without knowing the risk.
  • Privacy Concern: Checking passwords online using traditional APIs requires sending plain text passwords over network calls.
  • Our Solution: A hybrid local heuristic analyzer combined with zero-knowledge breach checking via HaveIBeenPwned API (k-Anonymity).

Evaluation Architecture

Immediate Rejections

  • Username contained in password
  • Leaked in > 300 data breaches
  • Empty password input

Interactive Warnings

  • Leaked in 1-300 data breaches
  • Fewer than 4 numeric digits
  • Missing uppercase / special chars
  • Potential birth year (1970–2015)

Privacy Protection: k-Anonymity

  • SHA-1 Local Hashing: Password is hashed on the user device.
  • 5-Character Prefix: Only first 5 characters of SHA-1 hash sent to api.pwnedpasswords.com.
  • Local Suffix Matching: Remote server returns matching hash pool; local script compares the remaining 35 characters.
Password -> SHA-1 Hash -> Prefix (5 chars to API) + Suffix (35 chars checked locally)

Implementations & Deployment

  • CLI Version (Python): Standalone terminal script utilizing standard Python libraries.
  • Web Version (HTML/JS): Client-side web application built with Web Crypto API (`crypto.subtle`).
  • GitHub Pages Deployment: Hosted directly on GitHub Pages for public availability.
